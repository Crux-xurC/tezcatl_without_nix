# Scope

What Tezcatl promises to work, what happens outside that, and what a person does there. Each promise has one sentence of why and links to
the file records that hold the details and the decisions. Xipe Totec's scope is in its own repository.

## How to read it (for people and AI reviewing or verifying)

- Something **inside the scope** that does not work is a bug: report it with steps to reproduce
- Something **outside the scope** that happens as written below is not a bug. Report it only if
  1. something other than what is written happens,
  2. data (text being edited, files on disk, the dictionary, books) is lost or broken in a way not written here, or
  3. going outside is invisible to the person (a silently different result)
- A boundary not in these tables: ask whether it is inside or outside before reporting it as a bug; once decided, add a row here
- When the scope changes (something outside comes inside, or the reverse), change this document

## Outside the scope

"What happens" is how the current implementation behaves; "What to do" is the remedy.
