Tezcatl launcher (minimal)

The minimal fallback of main.html: no page list, no image, only a hard-coded map of targets. It works even where the manifest (list_kinds/panels_and_skins.json) cannot be read.
A start page that does not depend on emacs. It opens no WebSocket. Type a command and Enter to open a window of input / output / dialogue-input / dialogue-output / xterm / w_list / skin / commands / nav / code / code_editor.

Grammar: new <target> [<how>]
<target> = input | output | dialogue-input | dialogue-output | xterm | w_list | skin | commands | nav | code | code_editor (required. Aliases: term=xterm, wlist / windows=w_list, basic=skin, codevi=code_editor)
skin = panels/skins/basic.html (a trial skin with input and output side by side; the leave key opens nav). w_list / commands / nav = panels/tool/list.html?config=… (the generic list). code = panels/resident/code.html (a read-only CodeMirror viewer), code_editor = panels/resident/code_editor.html (the file editor; its keymap is code.json's editorKeymap, vim by default). Alone it is a scratch; ?lang= hints the language
<how> = tab | window (default: launcher.open-mode of config.json)
Any word order; the leading new may be left out. E.g. new input / new output window / dialogue-input / xterm window / w_list

Windows opened: panels/resident/input.html?name=… / panels/resident/output.html?name=… / panels/resident/dialogue-input.html?name=… / panels/resident/dialogue-output.html?name=… (?name= is required: it goes on the relay's ledger of connections. dialogue-input / dialogue-output are the driving / observing sides of emacs-vent's dialogue bridge, the same vent connection as input / output), panels/resident/code.html?name=… / panels/resident/code_editor.html?name=… (CodeMirror viewer / editor. ?name= is the panel-bus identity, not a vent connection ── not on the ledger), panels/resident/xterm.html (the PTY terminal), relay-console/w_list.html (the relay's list of connections). The last two are not vent connections, so they take no ?name=. open w_list directly.
